# CryptoFamily

Открытый код учебной игры **FujiBall** и инструментов наблюдения за публичными котировками. Игра работает в браузере; TypeScript-версия пока существует как отдельный стартовый модуль.

## Играть и смотреть код

- [Открыть FujiBall](https://yogasnow.github.io/crypto-family/game/) · [исходники HTML/JavaScript](game/fujiball-spiral/) · [запуск и текущий статус](game/README.md).
- [TypeScript-модуль](game/typescript-starter/) — типы сцен, состояние и переходы; **ещё не подключён** к браузерной игре.
- [Учебные материалы](learning/README.md) · [скрипты Crypto Watch](watch/README.md).

## Запуск

Скачайте репозиторий и откройте `game/fujiball-spiral/index.html` в браузере. Для работы игры не нужны аккаунт, сервер или API-ключ. Прогресс хранится в браузере пользователя.

## Разработка

Текущая игра содержит восемь коротких сцен о музыке и небе. Чтобы продолжить её, начните с `game/fujiball-spiral/scenes.js` и `app.js`; для типизированной версии — с `game/typescript-starter/game.ts`. Скрипты Crypto Watch находятся отдельно в `watch/` и не подключены к игре.

Код TypeScript-модуля разрешён к повторному использованию по [MIT](CODE-LICENSE.md). Для остальных файлов лицензия повторного использования пока не указана; публичный доступ к исходникам сам по себе её не заменяет. [Происхождение публичной версии](PROVENANCE.md).
