# CryptoFamily · Teaching Laboratory

Открытая учебная лаборатория: небольшая игра, финансовая грамотность и прототип наблюдения за публичными котировками. Текущие игровые сцены — про музыку и небо; криптосценарии ещё предстоит написать. Это **не торговый сервис** и не рекомендация покупать криптоактивы.

## Цель, роли, материалы, статус, следующий шаг

- **Цель:** через игру и проверяемые упражнения научиться отличать факт, риск и гипотезу на крипторынке.
- **Роли:** авторское направление — Снежана; дизайн игры, разработка, редактура обучения и проверка данных — рабочие функции, конкретные участники не назначены.
- **Материалы:** [FujiBall](game/README.md), [учебный маршрут](learning/README.md), [Crypto Watch](watch/README.md), [публичный проект регламента](team/README.md).
- **Статус:** публичный репозиторий с локальными прототипами; приложения, торговля и автоматические уведомления не запущены.
- **Следующий шаг:** пройти игру с 3–5 тестировщиками, проверить доступность и игровые объяснения, затем проверить источники и задержку котировок Crypto Watch. Реальные сделки не входят в текущий этап.

## Начать

1. [Играть в FujiBall онлайн](https://yogasnow.github.io/crypto-family/game/) или [открыть локальные файлы](game/fujiball-spiral/index.html) после скачивания репозитория.
2. [Начать обучение онлайн](https://yogasnow.github.io/crypto-family/learning.html): деньги, риск, блокчейн, новости; подробности — в [учебном маршруте](learning/README.md) и [карте сценариев](game/SCENARIOS.md).
3. Посмотреть [код Crypto Watch](watch/README.md) и [пример оповещения](watch/alerts.md): котировки публичные, портфель учебный и вымышленный.
4. [Рисунок «for dragons» с питахайей](media/for-dragons.png) — художественная карточка проекта, не финансовый график.

## Для разработчика · открытый исходный код

- **Играть сейчас:** [онлайн-версия](https://yogasnow.github.io/crypto-family/game/) использует [HTML/JavaScript-исходники](game/fujiball-spiral/); точка входа — `index.html`, данные — `scenes.js`, логика и сохранение — `app.js`.
- **Продолжить на TypeScript:** [типизированный старт](game/typescript-starter/) содержит контракт сцены, состояние, три учебных черновика (риск, блокчейн, оповещение) и функцию перехода. Он ещё не подключён к опубликованной игре.
- **Рабочий маршрут:** [сценарии](game/SCENARIOS.md) → проверка источников → перенос существующих сцен → тестирование → новые криптоэпизоды. Правила командной работы — в [публичном проекте регламента](team/README.md).

Код открыт для изучения и предложений по развитию. Репозиторий не является предложением о продаже кода; перед коммерческим использованием или передачей прав условия нужно согласовать отдельно.

**Публичная версия ограничена намеренно:** внутренние командные регламенты, персональные уведомления и рабочая история сохранены отдельно в закрытом архиве. Полный Telegram-экспорт не заявлен. [Карта переноса](PROVENANCE.md).
