# FujiBall · учебная игра

[Запустить локальный прототип](fujiball-spiral/index.html): скачать файлы папки и открыть `index.html` в браузере. Сервер и торговый аккаунт не нужны.

Игра предлагает короткие сцены и выборы о риске, проверке фактов и последствиях решений. Прогресс хранится только в `localStorage` браузера; его можно экспортировать или удалить из интерфейса. Это рабочий вертикальный срез, не завершённое приложение и не обещание дохода.

**Проверить дальше:** пройти сценарий от начала до конца, проверить клавиатуру и мобильную ширину, провести 3–5 наблюдаемых тестов с людьми и записать непонятные формулировки. Ни деньги, ни реальные сделки в игру не подключать без отдельного проекта и проверки.
