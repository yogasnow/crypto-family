# Учебный маршрут

1. **Деньги и риск:** цель, бюджет, резерв, максимально допустимая потеря. Различать доходность, волатильность и ликвидность.
2. **Блокчейн как реестр:** транзакции объединяются в блоки; каждый блок связан с предыдущим криптографическим хешем. [Аналогия с бусами и белком](chains.md) показывает и сходство, и границы сходства.
3. **Новость о рынке:** записать источник, время, факт, гипотезу и то, чего пока не знаем, по [шаблону новости](news-template.md). «Хорошая новость» не равна сигналу покупать.
4. **Практика без денег:** оценить сценарий комиссии, падения цены и ошибки данных; затем пройти одну сцену [FujiBall](../game/).
5. **Мониторинг:** открыть [Crypto Watch](../watch/) и сравнить уведомление с исходными данными. Он наблюдает, не торгует.

Следующий учебный блок: простой TypeScript-словарь для активов и рыночных событий с явными типами `fact`, `hypothesis`, `unknown`.
