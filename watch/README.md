# Crypto Watch

Исходники инструментов для наблюдения за публичными котировками BTC и ETH:

- `daily_digest.py` печатает сводку;
- `monitor_once.py` сравнивает текущую котировку с локальными наблюдениями и печатает предупреждение при изменении от 2%; запуск по расписанию и доставка сообщений здесь не настроены;
- `bot.py` — отдельный Telegram-бот для одного владельца: котировки, объяснение и оповещения. Для него нужны переменные окружения `CRYPTO_WATCH_BOT_TOKEN` и `CRYPTO_WATCH_OWNER_ID`; действующий бот в этом репозитории не развёрнут.

Котировки запрашиваются у Coinbase Exchange. Скрипты не размещают ордера и не принимают деньги. Локальные SQLite-файлы и токены не входят в репозиторий.
